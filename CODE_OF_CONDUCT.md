# Code of conduct

Every space Lunchbox runs on GitHub follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). That's every issue and pull request, and every review and commit. This file links to the Covenant rather than copying it, and the linked text is the one that applies.

## Reporting

Use GitHub's **Report content** menu on the comment or thread, and choose **Report to repository admins**. That reaches the maintainer, Anthony Ledesma, privately. A commit or anything else without that menu goes to GitHub through its [report abuse form](https://github.com/contact/report-abuse).
