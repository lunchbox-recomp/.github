# Lunchbox

Lunchbox recompiles a GameCube game to run natively on a Mac. You build it from your own disc, and nothing from any game is in these repos. Lunchbox isn't affiliated with or endorsed by Nintendo or HAL Laboratory.

- **[Dragoon](https://github.com/lunchbox-recomp/dragoon)** is Kirby Air Ride recompiled to run natively on Mac.
- **[gcn-recomp](https://github.com/lunchbox-recomp/gcn-recomp)** is the recompiler and runtime Dragoon is built on. It's our fork of [upstream gcn-recomp](https://github.com/ethannicholas/gcn-recomp).

The most useful help is a bug report from someone who knows Kirby Air Ride, in [Dragoon's issues](https://github.com/lunchbox-recomp/dragoon/issues). Before a pull request, read [Dragoon's guide](https://github.com/lunchbox-recomp/dragoon/blob/main/CONTRIBUTING.md) or [the one for the fork](https://github.com/lunchbox-recomp/.github/blob/main/CONTRIBUTING.md).

Claude, Codex or local models running in [Pi](https://github.com/earendil-works/pi) write the code. I'm Anthony Ledesma, and I decide what gets built and check the results by playing it on my own disc. These docs are drafted the same way, and I edit them.
